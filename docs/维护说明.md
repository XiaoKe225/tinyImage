# TinyImage 维护说明

面向维护者的简要操作说明（用户向产品介绍见根目录 [README.md](../README.md)）。

## 目录结构

| 路径 | 职责 |
| --- | --- |
| `src/` | 前端（Vite + TypeScript） |
| `src-tauri/` | Rust 压缩引擎、队列、Tauri 壳 |
| `scripts/` | Pack、混淆、本机验收脚本（见下表） |
| `docs/` | 对外资源（如打赏收款码图）与维护说明 |
| `release/` | 本地 Pack 产物（gitignore，不入库） |
| `legacy-electron/` | 旧 Electron 对照，**不演进功能** |

根目录快捷入口：

| 文件 | 作用 |
| --- | --- |
| `开发构建.bat` | 仅前端 plain build（不混淆、不打 NSIS） |
| `加壳发布并校验.bat` | **推荐** Pack + SHA256 校验 |
| `加壳发布.bat` | Pack（无自动校验，维护者自用） |
| `打开release目录.bat` | 打开 `release\` 文件夹 |

## `scripts/` 脚本

| 脚本 | 用途 |
| --- | --- |
| `build.ps1` | Dev / Pack 主流程（混淆 + NSIS → `release\protected\`） |
| `obfuscate-dist.mjs` | Pack 前端 JS 混淆，写入 `dist\.obfuscated` 标记 |
| `verify-pin-local.ps1` | 图钉置顶本机五连验（CDP + Win32 TOPMOST） |
| `verify-speed-local.ps1` | T038 压缩加速五连验（设 `TINYIMAGE_T038_TIMING=1`） |
| `cdp-eval.mjs` | `verify-pin-local` 的 CDP 辅助（勿单独删） |

## 日常开发

```bash
npm install
npm run start
```

或双击根目录 `开发构建.bat`（仅前端 plain build，不混淆、不打 NSIS）。

## 加壳发布（须授权）

对齐 Denuvo 体感：**Dev 不混淆；Pack 必前端 JS 混淆**；禁止 UPX/Themida/MPRESS。

```bash
npm run pack:verify
```

或双击 `加壳发布并校验.bat`。

产出：

- `release/protected/TinyImage_*_x64-setup.exe`
- `release/protected/SHA256SUMS.txt`
- `release/TinyImage-*-win-x64-protected.zip`

助手执行 Pack 须用户当条写明 **「授权打包」**（或「授权 release」/「发布安装包」）。  
**「提交」≠ Pack。**

## Git

## 测试

```bash
npm run test:rust
npm run verify:pin-local
npm run verify:speed-local
```

| 命令 | 说明 |
| --- | --- |
| `test:rust` | 全量 Rust 单测（T038 体积/指纹；计时不强制） |
| `verify:pin-local` | 启动真实窗口，CDP 读 DOM + Win32 `WS_EX_TOPMOST`，连续 5 轮 |
| `verify:speed-local` | 连续 5 轮 `t038_speed_volume_tool_measured`，耗时+体积指纹须全过 |

`verify-speed-local` 会设置环境变量 `TINYIMAGE_T038_TIMING=1` 以启用耗时门禁；全量 `test:rust` 并行时 CPU 争用可能误报，故默认不强制计时。
