# TinyImage 维护说明

面向维护者的简要操作说明（用户向产品介绍见根目录 [README.md](../README.md)）。

## 目录结构

| 路径 | 职责 |
| --- | --- |
| `src/` | 前端（Vite + TypeScript） |
| `src-tauri/` | Rust 压缩引擎、队列、Tauri 壳 |
| `scripts/` | Pack：`build.ps1`、前端混淆 `obfuscate-dist.mjs` |
| `docs/` | 对外资源（如打赏收款码图）与维护说明 |
| `release/` | 本地 Pack 产物（gitignore，不入库） |
| `legacy-electron/` | 旧 Electron 对照，**不演进功能** |

## 日常开发

```bash
npm install
npm run start
```

或双击根目录 `开发构建.bat`（仅前端 plain build，不混淆、不打 NSIS）。

## 加壳发布（须授权）

对齐 Denuvo 体感：**Dev 不混淆；Pack 必前端 JS 混淆**；禁止 UPX/Themida/MPRESS。

```bash
npm run pack:verify
```

或双击 `加壳发布并校验.bat`。

产出：

- `release/protected/TinyImage_*_x64-setup.exe`
- `release/protected/SHA256SUMS.txt`
- `release/TinyImage-*-win-x64-protected.zip`

助手执行 Pack 须用户当条写明 **「授权打包」**（或「授权 release」/「发布安装包」）。  
**「提交」≠ Pack。**

## Git

须用户当条 **「提交」/「上传」/「push」**。
